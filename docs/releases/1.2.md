# Findex 1.2

Android versionName **1.2**, versionCode **3**, applicationId **app.findex.files**.
Signed with the same identity as v1.1 — it installs over v1.1 as a normal update.

## Changes

- **Launcher icon fixed**: the folder art now sits inside the adaptive-icon safe zone, so circle and squircle masks no longer clip its edges.
- **PDF viewer stabilized**: page rendering survives low-memory devices by retrying at a reduced resolution instead of crashing, and the viewer is covered by on-device smoke tests.
- **AI analyzer is faster and stops returning 404s**: retired provider defaults (for example `claude-sonnet-4-20250514`) are automatically mapped to current models, requests use faster model settings with smaller context, and a missing model now produces a clear message instead of a bare error code.
- **Local audio support with metadata**: audio files play locally and show detected artist, album, and duration (Android via MediaMetadataRetriever, web via the file itself). More audio formats are recognized (amr, awb, aiff, mka, wma).
- **Range selection**: shift-click selects every item between the last clicked file and the new one, like Shift on Windows. Works in list and grid views.
