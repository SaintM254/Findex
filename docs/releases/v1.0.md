## Findex 1.0

A full-screen Android file manager with a minimal glass interface, native storage operations, and reviewed assistant actions.

### Install

1. Download **Findex-1.0.apk** below.
2. Allow installation from your browser/file manager when Android asks.
3. Open Findex and grant **All files access** in Android Settings. Android 8–10 use the legacy storage permission flow.

**Requirements:** Android 8.0 (API 26) or newer and an up-to-date Android System WebView. The APK is a signed, minified release build, not a debug APK.

### Included

- Light, dark, and system appearance; edge-to-edge layout and inset selection controls.
- Folder creation, rename, favorites, copy/move, collision-safe paste, Trash and restore.
- Background metadata indexing and file operations with progress and cancellation.
- Native image, audio/video, and continuous PDF viewers, with external-app fallback.
- Local date/name search, reviewed batch organization, verified-duplicate cleanup, and storage reports.
- Optional OpenAI, Anthropic, and Gemini connections using personal API keys protected by Android Keystore.

### Verification and limits

- Web production build, 50 unit tests, and 20 desktop/phone browser checks pass.
- Android debug/release builds, native JVM tests, and lint are checked before this APK is signed.
- APK signatures and ZIP alignment are verified; a SHA-256 checksum and signing-certificate report are attached.
- Physical-device/OEM coverage and real paid-provider calls have not been certified. Review destructive actions and back up important files.
- Android-protected app directories/system partitions remain inaccessible. Codec availability depends on the device. Cloud metadata sharing is opt-in.

This release comes from the existing `arena/01a0caa2-findex` branch. No branch was merged. If you installed a separately signed development build, Android may require uninstalling it before installing this release.
