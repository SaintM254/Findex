# Findex 1.1

Android versionName **1.1**, versionCode **2**, applicationId **app.findex.files**.

## Install note

This version introduces a new signing identity because the original v1.0 private key could not be recovered. **Uninstall v1.0 first, then install this APK.** From v1.1 onward, updates (v1.2 and later) use this same identity and install normally.

## What changed

- Instant, traditional file browsing: folders open directly from storage with bounded pages; the recursive index no longer blocks startup, taps, or lists.
- Cached linear-time UI calculations, background-priority metadata scanning, deferred media/PDF probing, and a responsive hamburger.
- Screenshot cleanup: the top-right theme toggle and avatar, plus the main New folder/Add files row, were removed. Those tools live in navigation; theme options remain in Settings.
- Blue folder branding from the owner-supplied SVG and a lighter blue light/dark theme.

## Included assets

- `Findex-1.1.apk`, SHA-256 checksum, and the APK signature report.

The signing certificate SHA-256 for this identity is pinned in `signing/release-policy.json` and verified by CI before and after signing.
