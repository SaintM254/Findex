# Findex 1.2

Android versionName **1.2**, versionCode **3**, applicationId **app.findex.files**.

## Install note

This version carries a **new signing identity**, because the v1.1 private key was lost before it could be stored durably. **If you have v1.1 installed, uninstall it once, then install this APK.** This is the last identity change: v1.2 and every later version (v1.3, …) share this identity and install over each other as normal updates. The certificate SHA-256 is pinned in `signing/release-policy.json` and verified by CI before and after signing.

## Changes

- **Launcher icon fixed**: the folder art now sits inside the adaptive-icon safe zone, so circle and squircle masks no longer clip its edges.
- **PDF viewer fixed**: opening PDFs no longer crashes (the page list kept replacing a layout object Android needs; this is now covered by on-device smoke tests), and low-memory devices retry pages at reduced resolution instead of dying.
- **AI analyzer is faster and stops returning 404s**: retired provider defaults (for example `claude-sonnet-4-20250514`, `gpt-4.1-mini`) are automatically mapped to current models, requests use faster settings with smaller context, and a missing model now produces a clear message instead of a bare error code.
- **Local audio support with metadata**: audio files play locally and show detected artist, album, and duration (Android detects them from the file itself; the web viewer shows duration too). More audio formats are recognized (amr, awb, aiff, mka, wma).
- **Range selection**: shift-click selects every item between the last clicked file and the new one, like Shift on Windows. Works in list and grid views.
