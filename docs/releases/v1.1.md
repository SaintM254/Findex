# Findex 1.1 — published with a new signing identity

Android versionName **1.1**, versionCode **2**, applicationId **app.findex.files**.

## Signing identity

The original v1.0 private key was unrecoverable, so with owner authorization v1.1 introduced a **new signing identity** (4096-bit RSA, 10,000-day validity, alias `findex`).

- **Uninstall v1.0 once**, then install this APK. Android cannot install a differently signed package over an existing one.
- **v1.1 and every later version share this identity.** v1.2 installs over v1.1 as a normal update.
- The certificate SHA-256 is pinned in `signing/release-policy.json`; CI verifies the keystore, the signed APK, ZIP alignment, and package metadata against it before any release is published.
- The private keystore is durable only as the repository secrets `FINDEX_RELEASE_KEYSTORE_BASE64` and `FINDEX_RELEASE_KEYSTORE_PASSWORD` (or the encrypted local backup in the ignored `.release-signing/` directory). Store the secrets with `scripts/setup-release-secrets.sh`.

## Changes

- Traditional file-manager browsing: folders open immediately from storage with paged listings; the recursive index runs in the background and never blocks taps, lists, or startup.
- Cached linear-time calculations; background scans hold the writer lock only briefly; media/PDF probing deferred to idle time.
- Screenshot cleanup: removed the top-right theme toggle and avatar, and the main New folder/Add files row. Those tools are in navigation; theme choices remain in Settings.
- Blue folder icon from the owner-supplied SVG; lighter blue light/dark theme.
